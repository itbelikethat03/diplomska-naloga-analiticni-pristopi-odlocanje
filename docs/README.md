# Tehnični poročili

Delovni poročili, nastali med analizo. Nista del diplomskega dela, temveč
podrobnejši zapis izvedbe, ki stoji za poglavjema 5.3 in 5.4.

| Datoteka | Vsebina |
|---|---|
| `POROCILO_ML.md` | napovedni modeli nad podatki podjetja: podatkovna osnova, zasnova drsečega preverjanja, rezultati po modelih, detekcija anomalij, napoved časa reševanja |
| `POROCILO_NIJZ.md` | analiza čakalnih dob NIJZ: sestava panela, kakovost podatkov, anomalije, napovedni modeli, sinteza A8 |

**Opozorilo pri `POROCILO_NIJZ.md`:** poročilo opisuje stanje pred revizijo
kakovosti podatkov. Merodajne so številke, ki jih izpišejo skripte 10, 11, 20
in 21 iz `../03_nijz/skripte/`; razlike med staro in novo različico so
postavko po postavko popisane v `../03_nijz/rezultati/5_4_G2_primerjava.csv`.
